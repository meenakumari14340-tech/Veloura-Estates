# Veloura Estates – Real Estate Website

Veloura Estates is a luxury real estate frontend website developed using HTML, CSS, and JavaScript. It provides a user-friendly platform to explore premium properties, view detailed property information, save favourite properties, and book property visits. The website features an elegant design with gold accents, responsive layouts, and easy navigation.

**Technologies Used:** HTML, CSS, JavaScript

**Key Features:**
- Luxury real estate homepage
- About and Services pages
- Property listings with images and details
- Individual property details pages
- Wishlist to save favourite properties
- Property visit booking page
- Contact page
- Responsive and user-friendly interface

**Project Type:** Frontend Web Development
